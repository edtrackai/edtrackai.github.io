What we measure on this site

We use our own small analytics script, not Google Analytics or any third-party tracking service. It does not set cookies and does not store your IP address. For each page view or marked click it sends:

  • the event type (page view, or a click on a buy, download or other marked link) and, for clicks, which link (for example product name and position on the page)
  • the page path and the referring page address
  • campaign tags in the link you followed (utm_source, utm_medium, utm_campaign, utm_content)
  • a random session ID kept in your browser's sessionStorage, which your browser deletes when you close the tab
  • your approximate country, only if our hosting provider passes it in a request header, and whether the device looks like a mobile

The script runs on this site and sends these events straight to our own collection endpoint (a Neon Function at br-soft-rain-b9akm4v6-track.compute.c-7.eu-central-1.aws.neon.tech), not to any analytics company. If you arrive with campaign tags (utm_source, utm_medium, utm_campaign, utm_content, or ref) in the link, the script keeps them in sessionStorage for the rest of your visit, records them with each event, and adds them to links to Gumroad so a later purchase can be matched to the campaign. Closing the tab clears them.

This is stored in a database run for us by Neon (Neon Postgres, hosted in the EU, Frankfurt region). We use it only to count visits and see which pages and links lead to sales. We don't use it to identify you, build profiles, or advertise. Retention: [SHAH TO FILL: how long analytics events are kept, e.g. 13 months].
