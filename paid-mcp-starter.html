FAQ

How does billing work?
Each paid tool call sends a Stripe Billing Meter event with an idempotent identifier, so retries can't double-bill. Users get a free monthly quota, then an upgrade link in the tool result, with Stripe Checkout and the Customer Portal for subscriptions. A cron re-sends usage if Stripe calls fail.
Which MCP clients does it work with?
Claude Code, Cursor and Claude Desktop (via mcp-remote), using API keys. Claude.ai web connectors need OAuth, which is not included; the docs show where to swap it in.
Can I try it without Stripe or Supabase accounts?
Yes. Demo mode runs locally with one command and needs no Supabase or Stripe accounts.
What has been tested?
42 tests cover protocol (both spec eras), auth, quotas, metering, outage recovery, rate limits, webhook signatures, SQL/RLS and the Server Card / AI Catalog endpoints, and next build passes. A live Supabase project and live Stripe calls have not been tested, so run the launch checklist in Stripe test mode first.
Can I sell products built with it?
Yes. The single-developer commercial licence lets you build and sell unlimited products. You can't resell the template itself.
