FAQ

What do the guardrail hooks block?
They block reading or writing .env secrets and printing secret env vars; supabase db push, --linked commands, Stripe live mode, --prod deploys and force pushes; and the admin Supabase client, the Stripe SDK or server secrets in client components, plus NEXT_PUBLIC_*SECRET variables. They also typecheck after every TypeScript edit and won't let Claude say it's done while tests fail.
Does it work with Cursor, Codex or Copilot?
Yes. It ships as a Claude Code plugin or a copy-in .claude/ folder, plus Cursor rules, AGENTS.md for Codex, Copilot and Cline, and an .agents/skills mirror. The hooks are Claude Code specific.

Every code snippet in the skills compiles with tsc, is unit-tested and goes through next build against Next.js 16, Stripe SDK 23 and supabase-js 2. The plugin passes claude plugin validate --strict, and 13 hook test groups are included so you can re-run everything with npm run verify.
