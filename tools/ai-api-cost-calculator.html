How it’s calculated

cost per request = (input × (1 − cached share) × input price + input × cached share × cached price + output × output price) ÷ 1,000,000

cost per user per month = cost per request × requests per user per day × 30

monthly total = cost per user per month × users

requests per user per day under a cap = cap ÷ (cost per request × 30), rounded down

monthly total with a cap = users × the smaller of (cost per user per month, cap)

Months are 30 days. Every user is assumed to make the same number of requests. OpenAI lists long-context prices for requests over 272,000 input tokens, and Anthropic prices Claude Haiku 5.5 prompts over 100,000 tokens at a higher rate. Anthropic says the whole request then pays the higher prices. OpenAI's page doesn't say, so the calculator assumes the same for OpenAI.

What this doesn’t include

  • Batch, Flex, Fast and Ultrafast prices, and Anthropic fast mode: only Standard prices are used.
  • Cache writes, tool and web search fees, image and audio tokens, and reasoning tokens beyond what you enter as output.
  • Regional or data-residency uplifts (OpenAI) and US-only inference (Anthropic, 1.1×).
  • Taxes, credits and any discounts on your account.
