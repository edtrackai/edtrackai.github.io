What it checks

  • Keys: live Stripe keys in code, secrets in NEXT_PUBLIC_, service role in client components, .env in git
  • Auth: getSession() on the server, Server Actions without auth checks, open redirects, admin client misuse, roles in user_metadata
  • RLS: tables without RLS, using (true), anon writes, missing with check, unsafe security definer, views that bypass RLS
